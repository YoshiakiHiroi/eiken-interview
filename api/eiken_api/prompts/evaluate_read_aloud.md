## 採点観点

- 発音の明瞭さ
- 意味の区切り（チャンク）が自然か
- イントネーション（文末の上げ下げ、強勢）
- 速さ（速すぎ・遅すぎ）
- 読み飛ばし・読み違い

`transcript` と本文を比べ、読めなかった語・誤って発音した語を `mispronunciation:<word>` で `issue_tags` に入れてください。
