## 各回答の記録

${answers}

各項目の意味:
- `silence_before_sec`: 質問が終わってから話し始めるまでの秒数（長いほど反応が遅い）
- `duration_sec`: 回答の長さ（秒）
- `replay_count`: 質問を聞き直した回数（1回までは本番でも許容されるが、多いと減点）
- `clarity`: 声の大きさ・はっきりさの所見

## 採点（0〜${max_score} 点）

- ${max_score}: 自然に間を空けず、はっきりした声で積極的にやり取りできている
- 1〜2: 沈黙が長い、声が小さい、聞き直しが多い、などが目立つ
- 0: ほとんど応答できていない

## 出力

- `score`: 0〜${max_score} の整数
- `feedback_ja`: 日本語で2〜4文。どの回答で沈黙が長かったか、聞き直しが何回あったかなど、記録に基づいて具体的に書く。本番で "Could you say that again, please?" と聞き返すのは問題ないことも必要に応じて伝える。
